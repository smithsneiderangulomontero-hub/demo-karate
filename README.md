# demo-karate

![Karate CI](https://github.com/smithsneiderangulomontero-hub/demo-karate/actions/workflows/maven.yml/badge.svg)

Proyecto de testing de APIs con **Karate** (Java), construido como pieza de portfolio para procesos de QA Automation en España. Incluye entornos configurables, mocking con WireMock, cobertura CRUD completa, autenticación reutilizable y ejecución por tags.

## Stack

- **Java 17** (LTS, gestionado con [SDKMAN](https://sdkman.io/))
- **Maven** 3.9.x
- **Karate** 1.4.1 (JUnit 5)
- **WireMock** 3.9.1 — mock de API, sin dependencias externas
- **GitHub Actions** — CI/CD
